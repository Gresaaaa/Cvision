# Project Management Notes

## Suggested Board Setup

Use Jira or GitHub Projects with these columns:

- Backlog
- Ready
- In Progress
- Review
- Done

## Suggested Epic Breakdown

- Authentication and role system
- Candidate profile and resume management
- Job posting and company workflows
- AI analysis and scoring
- Admin and taxonomy management
- Infrastructure, testing, and CI/CD

## Suggested Sprint Outcome

Sprint 1:

- Core database schema
- Auth + RBAC
- Candidate and company onboarding

Sprint 2:

- Resume uploads
- Job CRUD
- Applications
- Search/filtering

Sprint 3:

- AI module
- Caching
- Background jobs
- Admin area

Sprint 4:

- Frontend integration
- Tests
- CI/CD
- Final documentation

## Collaboration Workflow

- Create feature branches per epic or story.
- Use pull requests for all changes.
- Require code review before merge.
- Run CI on each PR.
- Tag release candidates before final submission.
